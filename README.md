# Página de camisetas

La página consiste en crear un sitio web donde se puedan comercializar camisetas de cualquier empresa. 
La idea es que la página tenga un dieño agradable a la vista, que el usuario se pueda mover con libertad y que logre entedender las diferentes funcionalidades que la página tiene. 

> [!IMPORTANT]
> Por razones obvias, esta página no será funcional al 100%, esto es solo un proyecto personal con el objetivo de mejoramiento personal en programación :)

### Objetivo
* Mejorar habilidades y conceptos en el UI/UX
* Aprender JS de mejor forma (promesas, manejo correcto del DOM, etc)
* Hacer una página funcional (**No** en la parte monetaria)

### Tecnologías usadas
* HTML5 -> (Estructura general de la página)
* JavaScript -> (Dinamismo en la página)
* CSS -> (Estilos de la página)
* Jason -> (como base de datos)

### Paleta de colores
* sand-clear: #F2EDE3;
* verde-oscuro: #45594E;
* verde-salvia: #8DB58A;
* amarillo-crema: #F4E0A6;
* ocre-dorado: #D4B774;
* marron-arena: #A69068;
* blanco: #FDFBF7;
* pure-white: #e0e0e0;

**Usos para cada color:**  

* **Verde Oscuro** -> texto principal (títulos, cuerpo de texto importante), 
                pies de página (footer) y elementos que necesiten mucha legibilidad.
                También funciona increíble para botones secundarios.

* **Verde Salvia** -> botones de "Añadir al carrito", iconos, elementos de carga o secciones 
                destacadas

* **Amarillo Crema** -> fondos de secciones especiales, tarjetas de productos (cards) con fondo 
                    claro o para resaltar ofertas/promociones sin ser agresivo.

* **Ocre Dorado** -> detalles sutiles como etiquetas de precios, bordes de elementos, o incluso 
                para enfatizar el estado de "Agotado/En oferta".

* **Marrón Arena** -> para textos secundarios, descripciones pequeñas de productos, líneas divisorias 
                muy finas o iconos de menor importancia.
